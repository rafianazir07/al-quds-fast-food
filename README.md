# Al Quds Fast Food Website

A responsive Next.js restaurant website for Al Quds Fast Food, Rawalpindi.

## Included

- Responsive restaurant landing page
- Menu categories and add-to-cart controls
- Combo deals
- Gallery with graceful image fallbacks
- Persistent cart using localStorage
- Delivery details form in the cart
- WhatsApp order handoff
- Click-to-call and Google Maps directions
- Accessible mobile navigation and cart drawer
- Restaurant metadata and Schema.org structured data

## Run locally

```bash
npm install
npm run dev
```

For a production check:

```bash
npm run build
npm run start
```

## Important before launch

1. Replace the sample gallery photography with the restaurant's own photos if available.
2. Verify every menu name, description, price, phone number, address and opening hour against the current printed menu.
3. Replace the placeholder domain in any future SEO/social metadata with the real production domain.
4. Confirm the WhatsApp number and delivery policy with the restaurant.
5. Test the site on a real phone before publishing.

The project intentionally does not include `node_modules`; install dependencies with `npm install`.
